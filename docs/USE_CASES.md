# Use cases

- Visitor browses and filters public college records.
- Student registers, signs in, updates profile, gets explainable recommendations, saves favorites, compares 2–4 colleges, and revisits recommendation history.
- Admin signs in with a provisioned account, views dashboard counts, and manages college/course/branch/cutoff/placement records.
- System validates inputs, rejects unauthenticated protected calls, and restricts admin routes by role.
