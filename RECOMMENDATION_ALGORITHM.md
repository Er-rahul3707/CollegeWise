# Recommendation algorithm

Candidates come from a bounded database query (first 1,000 by name), then sort deterministically by score and college name. Factors: within-budget fees (25; missing budget/fees earns 12 with a concern), preferred state (15), city (10), course and branch confirmed by relevant cutoff rows (10 each), required hostel availability (10; when not required, 5), published ranking (up to 10), meeting a relevant entrance cutoff (20), and latest placement outcome (up to 10: up to 5 from placement rate and up to 5 from average package normalized against ₹30 lakh). Scores clamp to 0–100. A cutoff match returns `MEETS_CUTOFF`; a miss returns `BELOW_CUTOFF`; missing or non-comparable cutoff data returns `INSUFFICIENT_DATA`. Reasons and concerns are built from matching data.

This is a screening aid, not an admission probability. 10th/12th percentages are stored but not currently scored because cutoff records do not model school-percentage thresholds. Missing placement records contribute no points and add a concern. The demo catalogue seeds 20 illustrative colleges with related examples; these are not authoritative admissions or outcomes data. Verify cutoffs, seat matrices, categories, placement reports, fees, and institutional policies before real decisions. The same profile and database state produce the same scores.
